# StyleWriter Desktop

风格化文章生成器 - 混合智能体架构

## 架构

```
┌─────────────────────────────────────────────────────────┐
│                    客户端                                 │
│               (GUI / API / Web)                          │
└─────────────────────────────────────────────────────────┘
                        ↓ HTTP API
┌─────────────────────────────────────────────────────────┐
│                  API 网关 (FastAPI)                       │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│              混合智能体服务 (HybridAgent)                  │
│  ┌─────────┐  ┌──────────┐  ┌─────────────┐            │
│  │ Agent   │→ │ 模型选择  │→ │ 后处理器    │            │
│  │ (RAG)   │  │ API/本地  │  │             │            │
│  └─────────┘  └──────────┘  └─────────────┘            │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│                   存储层                                  │
│  ┌──────────────┐  ┌──────────────┐                     │
│  │ 向量数据库   │  │ 模型权重     │                     │
│  │ (FAISS)      │  │ (LoRA)       │                     │
│  └──────────────┘  └──────────────┘                     │
└─────────────────────────────────────────────────────────┘
```

## 快速开始

### 1. 安装依赖

```
双击 install.bat
```

### 2. 启动程序

```
双击 run.bat
```

### 3. 配置

在设置区配置:
- **云端 API**: API Key、Base URL、模型
- **本地模型**: 微调模型路径

### 4. 使用

1. 导入示例文章
2. 创建向量索引
3. 选择模型（API 或本地）
4. 生成文章

## 云端训练

训练脚本在 `training/` 目录，可独立上传到 Ubuntu 服务器。

详见 `training/README.md`

```

│   ├── agent/

├── config/
│   └── settings.json    # 配置文件
├── data/
```

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/generate | POST | 生成文章 |
| /api/search | POST | 检索参考 |
| /api/status | GET | 服务状态 |
| /api/reload | POST | 重新加载 |

## 系统要求

- Windows 10/11
- Python 3.8+
- 网络（使用 API 时）
- GPU（使用本地模型时）
