## 核心模块

### 1. HybridAgent (混合智能体)

位置: `server/agent/hybrid_agent.py`

职责:
- 协调 RAG 检索和模型生成
- 管理多种推理引擎
- 处理用户请求

### 2. LlamaCppEngine (llama.cpp 引擎)

位置: `server/core/llama_engine.py`

职责:
- 调用 llama.cpp 进行推理
- 管理 GPU 显存分配
- 处理 GGUF 模型

### 3. DataCleaner (数据清洗)

位置: `server/core/data_cleaner.py`

职责:
- 解析多种文件格式
- 清洗和规范化文本
- 分块处理

### 4. FastAPI 服务

位置: `server/api/app.py`

职责:
- 提供 REST API
- 处理 HTTP 请求
- 管理会话

### 5. GUI 界面

位置: `server/gui/main_window.py`

职责:
- 提供图形界面
- 用户交互
- 状态显示

## 数据流

```
用户输入 → GUI/API → HybridAgent
                         ↓
                    RAG 检索参考
                         ↓
                    构建 Prompt
                         ↓
              ┌──────────┴──────────┐
              ↓                     ↓
         本地模型                云端 API
      (llama.cpp)            (OpenAI等)
              ↓                     ↓
              └──────────┬──────────┘
                         ↓
                    后处理
                         ↓
                    返回结果
```

## 技术栈

| 层级 | 技术 |
|------|------|
| GUI | tkinter |
| API | FastAPI + Uvicorn |
| 推理 | llama.cpp / Transformers |
| 向量 | FAISS / Sentence-Transformers |
| 训练 | PEFT + TRL |
| 打包 | NSIS / PyInstaller |
